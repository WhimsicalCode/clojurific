Clojurific is optimized for interoperability with modern JavaScript tooling, runtime performance and build speed.

  • Compiles ClojureScript to ES modules
  • Runs as a Vite plugin, offering fast hot reload in dev and easy interoperability with JavaScript libraries
  • Compatible with existing ClojureScript libraries
  • Browser and backend support
  • Integrated MCP and REPL in dev for both browser and backend
  • Up to 5x faster builds compared to classic ClojureScript compiler
  • About 40% faster on runtime benchmarks
